# Figma 导航跳转速查

文档内"导航 / 跳转"相关技巧的速查手册，按主题索引。内容经 Figma 官方文档核实 + 实际验证，每个主题含 **场景 → 做法 → 坑**。

## 这是什么

记录在 Figma（桌面版）实战中验证过的跳转/导航技巧。**只收录实际用到并验证过的做法**，未验证的暂不入库：

| # | 主题 | 一句话 |
|---|---|---|
| 1 | 编辑模式：文字链接导航 | 给文字加链接指向"本文件画板/页面"，编辑模式下点击直接跳，不用进原型 |
| 2 | 编辑模式：快速定位 | `Ctrl+/` 输名字跳 / 左栏点击跳 / Section 做目录 / `Shift+2` 缩放定位 |

> 说明：原型连线跳转（播放模式）、板内 Overlay/Scroll To、连线治理、Create component 区分等，因未在本环境验证，暂不收录。
